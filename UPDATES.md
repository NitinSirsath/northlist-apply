# What's new

The AI shows the versions you missed at `start`, then reads the new rules.

## 2026.11.27

New for you:
- Today's plan is a page: tap the sites, set how many jobs with + and −, press Start. It never lets you go above a site's daily limit, and guesses how long the run takes.
- NorthList shows each run as a task, named by when it started ("Yesterday 9:02 pm"), with how many it sent per site and how long it took.

Before → Now:
- Type `linkedin 10, workday 2` in the chat → tap it on a page (typing in the chat still works).
- One long list of applications in NorthList → one group per run.

## 2026.11.26

New for you:
- Skips fewer jobs: for experience only when a job asks for more than 3 years above yours, for skills only when its main skill is one you don't have.
- Never stops for you: it answers judgment questions itself (like "rate your JavaScript") and waits at most 5 minutes for a sign-in or an upload.
- Setup is cleaner and asks a few more details once (birth date, gender, your links), so fewer jobs wait for you.

Before → Now:
- 1.5 years of experience saved as 1 → 1.5, counted from your job dates.
- Every skipped job sent to NorthList → only jobs it tried and could not finish, with the reason.

## 2026.11.25

New for you:
- Today's run: a page at the end of every run with what your AI applied to, what it skipped, and its questions for you, with buttons to answer.
- Connect NorthList in one click from its Setup tab: Codex and Claude Code open with the setup ready.

Before → Now:
- A long summary and questions in the chat → one page, answered with taps.
- Download the folder, then paste a prompt with your token → one button; your AI finds or downloads the folder.

## 2026.11.24

New for you:
- Setup is a page with buttons: drop your resume and most answers fill in by themselves.
- NorthList Apply now updates itself at `start`.

Before → Now:
- One setup question per message → one page, filled from your resume.
- A long chat could forget rules → the run tells you when to open a new chat.
