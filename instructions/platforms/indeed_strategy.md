# Indeed

Adds only Indeed's steps to `AGENTS.md`; if the two ever conflict, `AGENTS.md` wins.

## Search
1. Open Indeed and search the target job titles from `personal_data/profile.md`.
2. Choose the newest-first sort and Past 24 hours when Indeed offers them (`AGENTS.md` section 9).
3. Prefer jobs marked "Easily apply" (or whatever Indeed's own apply label is now).

## Apply
1. Start Indeed's application flow for the job.
2. Compare prefilled values with `profile.md`, and answer employer questions from `form_answers.md`.
3. Submit and wait for Indeed's confirmation.

## Skip
- Jobs that need a required skills test or assessment before submitting, unless the user saved an answer or a way to do it.
