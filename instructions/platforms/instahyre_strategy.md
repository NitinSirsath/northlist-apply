# Instahyre

Adds only Instahyre's steps to `AGENTS.md`; if the two ever conflict, `AGENTS.md` wins. Keep this flow careful: these instructions do not fix Instahyre's screens.

## Search
1. Open Instahyre and look at its current job and search pages.
2. Use the target job titles, locations and work modes from `personal_data/profile.md`, and Instahyre's freshness controls when it has them (`AGENTS.md` section 9).
3. Never assume a button name, a form order or a quick-apply behaviour that the page does not show.

## Apply
1. Follow the application flow the current page shows.
2. Compare prefilled values with `profile.md`, and answer only from the saved data and matching contextual answers.
3. Wait for Instahyre's confirmation. Without it, add a `skipped` or `needs_user` entry with the exact reason.
