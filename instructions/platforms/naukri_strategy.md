# Naukri

Adds only Naukri's steps to `AGENTS.md`; if the two ever conflict, `AGENTS.md` wins.

## Search
1. Open Naukri search with the skills and target job titles from `personal_data/profile.md`.
2. Set the experience filter from the profile.
3. Use Naukri's freshness controls when it has them (`AGENTS.md` section 9).

## Apply
1. Review the profile details Naukri will send with the application.
2. Naukri's **Apply** can submit at once, so it is a submit action: keep the 2-minute gap before it. For the session's first application, show the user the job and the profile details Naukri will send, and get the user's `ok` before clicking it.
3. Click **Apply**. If questions appear, answer from the saved data and matching contextual answers, and compare prefilled values before the final submit.
4. Wait for Naukri's confirmation.

## Skip
- Jobs whose location or work mode does not match `profile.md`.
